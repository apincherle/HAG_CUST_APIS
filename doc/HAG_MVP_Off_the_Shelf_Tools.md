
# HAG Pokémon Grading – Off-the-Shelf Tools for POC / MVP

This document lists **ready-to-use, off-the-shelf tools, APIs, and services**
you can use **immediately** to build a **POC / MVP** of the HAG Pokémon grading platform,
minimizing custom ML and hardware complexity.

Focus: **fast validation**, **low engineering overhead**, **Azure-friendly**, **Pokémon-first**.

---

## 1. Submission, Users, and Core Backend

### Backend API
- **Spring Boot 3.x**
  - REST APIs
  - Grading orchestration
  - Rules engine
- **Azure App Service**
  - Host Spring Boot with minimal DevOps
- **Azure API Management** (optional)
  - Rate limits, auth policies

### Database
- **Azure PostgreSQL Flexible Server**
  - System of record
  - Strong relational model

### Auth
- **Azure AD B2C** (optional)
  - Client login
- OR Spring Security + JWT

---

## 2. Storage & Media Handling

### Image & Asset Storage
- **Azure Blob Storage**
  - Raw scans
  - Cropped images
  - Label PDFs
  - Slab photos

### Upload Pattern
- **SAS URLs**
  - Secure direct upload from imaging stations
  - Avoids API bottlenecks

---

## 3. Physical Imaging (Off-the-Shelf Hardware)

### Scanning
- **Epson Perfection V600** (budget)
- **Epson Perfection V850 Pro** (recommended)

### Camera Imaging
- **Sony A6400 / A6000**
- **Canon EOS R50**
- **Macro lens (90–100mm)**

### Lighting
- **Aputure / Neewer LED panels**
- Diffusers / softboxes

### Microscopy
- **Dino-Lite Edge Series**
- **Plugable USB microscope** (POC)

### UV
- **Convoy S2+ UV flashlight**
- Dark box enclosure

---

## 4. Job Orchestration & Async Processing

### Queues
- **Azure Service Bus**
  - CARD_IMAGED
  - CARD_IDENTIFIED
  - CARD_AUTH_PASSED

### Workers
- **Spring Boot worker**
- OR **Python FastAPI worker** (recommended for CV)

---

## 5. Card Identification (What card is it?)

### OCR
- **Azure AI Vision (OCR)**
  - Card name
  - Card number (e.g. 4/102)
  - Text bounding boxes

### Metadata Lookup
- **Pokémon TCG API**
  - Canonical card info
  - Set, rarity, variant
- **TCGplayer API** (optional pricing reference)

### Image Matching (optional POC)
- **Azure Cognitive Search**
  - Fuzzy matching
  - Future image embedding support

---

## 6. Authenticity Verification (Is it real?)

### Dimensions / Trim Detection
- **OpenCV**
  - Measure borders
  - Detect trimming
  - Warp analysis

### Print Pattern (Micro)
- **Azure Custom Vision**
  - Train with genuine vs fake microscope images
- **Azure Machine Learning**
  - Optional upgrade for deeper models

### UV Response
- **Azure Custom Vision**
  - Expected fluorescence classification
- OR Rule-based threshold detection

---

## 7. Condition Grading (How good is it?)

### Centering
- **OpenCV**
  - Deterministic border ratio measurement
  - Most reliable automated metric

### Corners
- **Azure Custom Vision**
  - Classes:
    - Sharp
    - Slight whitening
    - Heavy whitening
    - Ding

### Edges
- **Azure Custom Vision**
  - Detect chips, frays, nicks

### Surface
- **Azure Custom Vision**
  - Scratches
  - Print lines
  - Dents
- **OpenAI Vision API** (optional)
  - Cross-check reasoning
  - Natural-language defect summaries

---

## 8. Grading Logic & Explainability

### Rules Engine
- **Custom Spring Boot service**

  - Policy-driven auto-approval

### Explainability
- **Custom Vision heatmaps**
- Stored defect metadata
- Text summaries generated by rules engine

## 12. What to Use for a FAST MVP

### Minimal Stack (Recommended)
- Spring Boot + Azure App Service
- Azure PostgreSQL
- Azure Blob Storage
- Azure Service Bus
- Azure AI Vision (OCR)
- Pokémon TCG API
- OpenCV (centering + trim)
- Azure Custom Vision (corners, edges, surface)

### What to Skip Initially
- Advanced AML models
- IR imaging
- Full 3D surface scanning
- NFC tags

---

## 13. MVP Success Criteria

- Card can be:
  - Submitted
  - Scanned
  - Identified
  - Graded
  - Reviewed
  - Returned
- Grades are:
  - Explainable
  - Repeatable
  - Auditable
- Manual intervention < 30%
